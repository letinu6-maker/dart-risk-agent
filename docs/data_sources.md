## 라벨 정의

- **예측 시점**: t년 사업보고서 제출일 (접수번호 앞 8자리). 변수는 이 보고서와 t년 공시로만 만든다.
- **사건(위험=1)**: 제출일 + 30일 이후 1년 안에 관리종목 지정 또는 상장폐지 사유 발생·결정
- **제외(label 없음)**: 제출일 후 30일 안에 사건이 난 행. 이미 공개된 감사의견 때문에 바로 생긴 사건이라 '예측'이 아니므로 0도 1도 아닌 것으로 보고 학습·평가에서 뺀다. 30일·1년은 `build_dataset.py --gap-days --horizon-days`로 조정
- **생존 편향 방지**: 상장폐지 기업은 현재 상장 목록에 없으므로, 사건 기업을 표본에 따로 전부 넣는다
- **팀 확인 필요**: `data/labels/events.csv`의 `report_nm`을 훑어 부실과 무관한 사건이 섞였는지 확인
