## 라벨 정의 (초안 — 팀 합의 필요)

- **사건(위험=1)**: t+1년에 ① 상장폐지 ② 관리종목 지정 ③ 감사의견 비적정 중 하나 이상 발생
- **변수**: t년 사업보고서(통상 t+1년 3월 제출) 기준 지표만 사용
- **누수 점검**: 사건일 이후 제출된 공시는 변수에서 제외. 상장폐지 사유가 "감사의견 거절"이면 같은 감사의견을 변수로 쓰지 않도록 시점 확인
