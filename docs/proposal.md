# 기획 요약

원본: 「공시 변화 기반 상장기업 재무위험 조기경보 AI Agent」 아이디어 제안서 (김나형)

## 문제

개인투자자와 초급 애널리스트는 상장폐지, 관리종목 지정, 감사의견 비적정 같은 위험 신호를 늦게 알게 된다.

- **읽기 어렵다**: 사업보고서·감사보고서는 수백 쪽이라 매번 비교하기 어렵다.
- **놓치기 쉽다**: 기존 서비스는 재무비율 위주이고 주석·문구 변화는 거의 다루지 않는다.
- **이유를 모른다**: 위험하다는 결론만 있고 근거 설명이 없다.

## 심사 기준 대응

| 평가 항목 (배점) | 대응 |
|---|---|
| 문제 정의·주제 적합성 (20) | 투자·금융 실무의 실제 문제(위험 기업 조기 파악) |
| AI Agent 구성·설계 (25) | 수집→탐지→예측→리포트 4단계, 도구 호출이 분명함 |
| 차별성·창의성 (20) | 숫자뿐 아니라 공시 문구 변화까지 반영 |
| 실현 가능성 (20) | OpenDART 무료 API, 단계별 MVP |
| 활용성·확장성 (15) | 개인투자자, 애널리스트, 여신·투자 심사 |

예선: 전문가 70% + 상호평가 30%

## MVP 단계

| 단계 | 내용 | 비고 |
|---|---|---|
| 1 (필수) | OpenDART로 재무제표·감사의견 수집 → 재무지표 → 위험도 모델 학습 | 이것만으로 MVP |
| 2 (필수) | LLM 리포트, 데모 URL | 본선 필수 제출물 |
| 3 (선택) | 문구 변화량(TF-IDF 유사도) 변수 추가, 추가 전후 성능 비교 | 차별성·가점 강화 |

## 리스크

| 리스크 | 대응 |
|---|---|
| 데이터 누수 | 시간 기준 분리, 사건 이후 공시 제외 |
| 불균형 | Recall, PR-AUC, 가중치 조정 |
| 출처 미기재 (-10) | `data_sources.md` 표 유지 |
| 일정 지연 | 3단계는 선택, 1~2단계 우선 |
| 노트북 실행 불가 | 제출 전 새 환경 재실행 |
